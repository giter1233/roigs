# SAM2 交互式标注使用指南

## 功能概述

新的交互式标注功能允许您通过鼠标点击来实时标注目标，而不需要预先设定坐标点。这使得标注过程更加直观和灵活。

## 使用方法

### 1. 运行交互式标注程序

```bash
cd /home/hbw/improve/sam2
python segimage_interactive.py
```

### 2. 交互式标注操作

当程序显示第一张图片时，您可以进行以下操作：

#### 鼠标操作
- **左键点击**: 添加前景点（绿色圆点）- 标记您想要分割的目标区域
- **右键点击**: 添加背景点（红色圆点）- 标记您不想包含的背景区域

#### 键盘操作
- **U键**: 撤销最后一个标注点
- **C键**: 清除所有标注点，重新开始
- **回车键/空格键**: 完成标注，开始分割处理

### 3. 标注策略建议

#### 基本标注
- 在目标对象的中心或明显特征区域点击几个前景点
- 如果目标较大或复杂，可以在不同部位添加多个前景点

#### 精确分割
- 如果分割结果包含了不需要的背景区域，添加背景点来排除
- 背景点应该放在您不希望包含在分割结果中的区域

#### 示例标注流程
1. 在目标对象上点击3-5个前景点（左键）
2. 如果有误分割的背景，在那些区域添加背景点（右键）
3. 按回车键完成标注

## 与原版本的区别

### 原版本 (segimage.py)
- 需要手动修改代码中的坐标
- 坐标格式：`"coords": np.array([[x1, y1], [x2, y2], ...], dtype=np.float32)`
- 标签格式：`"labels": np.array([1, 1, 0, ...], dtype=np.int32)`

### 交互式版本 (segimage_interactive.py)
- 通过鼠标点击直接标注
- 实时可视化标注点
- 支持撤销和重新标注
- 更直观的用户体验

## 输出结果

程序会生成以下四种类型的文件：

1. **分割结果图** (`../data/shibei/segmenteds/`)
   - 原图叠加蓝色掩码的可视化结果

2. **裁剪对象图** (`../data/shibei/cropped/images/`)
   - 裁剪出的目标对象，带透明背景

3. **透明背景图** (`../data/shibei/masked_images/`)
   - 完整尺寸图片，背景透明，仅保留目标对象

4. **纯掩码图** (`../data/shibei/pure_masks/`)
   - 黑白掩码图，用于3D Gaussian Splatting训练

## 用于3D Gaussian Splatting训练

生成的纯掩码图可以直接用于之前集成的mask训练功能：

```bash
# 使用mask进行训练
python train.py -s data/shibei --use_mask

# 测试mask加载
python test_mask_training.py --source_path data/shibei
```

## 故障排除

### 常见问题

1. **程序无法启动**
   - 确保已安装SAM2依赖：`pip install --no-build-isolation -e .`
   - 检查模型文件是否存在：`checkpoints/sam2.1_hiera_large.pt`

2. **标注窗口无响应**
   - 确保matplotlib后端支持交互：`pip install matplotlib`
   - 在Linux环境下可能需要X11转发

3. **分割效果不理想**
   - 增加更多前景点，特别是在目标的关键特征区域
   - 添加背景点来排除误分割的区域
   - 尝试不同的点击位置和组合

4. **内存不足**
   - 减少图片数量或分辨率
   - 在Config类中设置`USE_GPU = False`使用CPU模式

### 调试模式

如果需要查看详细的处理过程，可以修改代码中的预览间隔：

```python
# 在Config类中修改
VIS_STRIDE = 10  # 每10张图显示一张预览（原值60）
```

## 技术细节

### 交互式标注实现
- 使用matplotlib的事件系统捕获鼠标和键盘输入
- 实时更新标注点的可视化显示
- 支持多种标注操作（添加、撤销、清除）

### 兼容性
- 与原有的SAM2分割流程完全兼容
- 生成的掩码格式与训练代码要求一致
- 支持所有常见图片格式（JPG、PNG、BMP等）

## 总结

交互式标注功能大大简化了SAM2的使用流程，让用户可以更直观地进行目标标注，特别适合：

- 需要精确控制分割区域的场景
- 目标对象复杂或边界不清晰的情况
- 快速原型开发和实验
- 教学和演示用途

结合之前集成的mask训练功能，现在可以实现从交互式标注到3D重建的完整工作流程。
